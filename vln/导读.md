# VLN（视觉语言导航）领域导读

> 本组 5 篇精读编号 71–75，面向自动驾驶方向科研新手。目标：用 VLN 的"指令跟随"经验照亮开放式自然语言驾驶指令这个课题。

## VLN 的 landscape：从室内走廊到真实街道

VLN 的标准问题是：给智能体一段自然语言指令（"走出卧室，左转，停在厨房桌子旁"），它要在没见过的环境里走到终点。领域演进分三段：

**第一段：室内离散时代（2018–2021）。** R2R（CVPR 2018）在 Matterport3D 室内全景图上定义任务：环境是一个离散导航图，智能体每次从几个候选视点里选一个跳过去。RxR 把指令写得更长、更多语言。VLN-CE 把离散跳跃换成连续环境里的低级动作。这个阶段的主力是专用小模型（HAMT、DUET），结构是"视觉编码器 + 跨模态 Transformer + 动作分类头"。

**第二段：LLM 接管（2022–2024）。** 两个入口：一是把 LLM 当零样本 planner（NavGPT，AAAI 2024：把观测转成文字喂给 GPT-4 做决策）；二是把 LLM/VLM 本身训成导航模型（NaviLLM、NavGPT-2、NaVid）。核心争论从"网络结构怎么设计"变成"LLM 的推理能力到底能不能直接变成导航动作"——NavGPT-2 的答案是不能，中间要隔一个策略网络。

**第三段：户外与真实世界。** 室内全景图和驾驶差得太远，真正与你相关的分支是户外：LM-Nav（CoRL 2022）在真实郊区街道上跑数百米，三个预训练模型零微调组合；更早的 Touchdown（2019）用纽约街景做指令导航。户外 VLN 的难处——开放式指令、动态环境、长距离——和驾驶是同一类难处。

## 新手阅读顺序

**71 → 74 → 73 → 72 → 75**，理由：

1. 先读 **71 LM-Nav**：三个盒子、一条流水线，没有复杂公式，是理解"LLM 如何参与导航"的最简模型。读完你会有一个具体画面：指令进来，变成路标，路标钉在地图上，车开过去。
2. 再读 **74 MapGPT**：在 71 的画面上加一个东西——记忆。地图怎么变成文字、文字怎么进 prompt、规划怎么从单步变多步，都是直观的工程，没有训练。
3. 然后 **73 NavGPT-2**：开始上强度。Qformer 视觉对齐、冻结 LLM、策略网络吃隐表示，这里的"分工"思想直接对应你的"LLM 调度器 + 专家规划器"。
4. 再读 **72 NaviLLM**：schema 统一范式，偏表示设计。放在 73 之后读，你会明白"统一输入格式"和"分工"是同一枚硬币的两面。
5. 最后 **75 NaVid**：视频 token 机制、两路 token、连续动作，工程细节最多，放在最后啃。它的 Sim2Real 讨论对你做 Bench2Drive 闭环验证有直接参考。

每篇末尾的"与本课题的关联"都写了具体的咬合点，读的时候对照着看。

## VLN 方法往驾驶迁移的要点

**第一，指令分解是通用动作。** LM-Nav 让 GPT-3 把"去药店再回家"拆成路标序列；你的开放式驾驶指令（"超前面那辆慢车"）同样需要先拆成"变道—加速—并回"子目标再调度规划器。分解的粒度决定了调度器的设计。

**第二，grounding 是指令跟随的生死线。** VLN 里"停在厨房桌子旁"能不能对上视觉里的桌子，决定任务成败；驾驶里"跟上前面那辆白车"的指代消解是同构问题。CLIP 式图文对齐的误匹配模式（74、71 的怀疑式审读里都有具体例子）值得你提前记在小本子上。

**第三，记忆有显式和隐式两条路。** MapGPT 把在线地图写成文字塞进 prompt（显式、外化）；NaVid 把历史压进视频 token（隐式、内化）。NaVid 的解读里给出了分界线：隐式记忆在约 90 步/20 米尺度后衰减——超过这个尺度，就需要你课题里的显式情景记忆模块。这是一个可以直接拿来做实验设计的论据。

**第四，"LLM 推理、专家动作"的分工已被验证。** NavGPT-2 最硬的发现：拿掉策略网络 SR 从 67.5 崩到 21.5，而 LLM 推理预训练只值 +0.77。这给你一个定心丸：LLM 调度器 + 专家规划器的分工不是妥协，是被数据支持的更优架构。

**第五，评估方式的教训。** VLN 用 SR/SPL 在离散图上评，驾驶要在闭环里评；但 VLN 的 zero-shot 泛化评估（未见环境、未见指令风格）正是开放式指令最需要的评测维度。设计你的 Bench2Drive 评测时，可以借用"未见指令"的划分思路。

## 未确认事项总览

各篇解读末尾都有"未确认清单"，这里只列影响你后续使用的三条：
- LM-Nav（71）：目标函数超参数 γ/α 的取值全文未给；拓扑图规模未给——复现其搜索算法时需自己定。
- NaviLLM（72）：多任务数据采样配比全文未写，这是复现的最大缺口。
- NaVid（75）：公开发布的权重是 Uni-NaVid 数据配方训的版本，数字高于论文——引用其 R2R 数字时以论文为准，不要抄仓库 README。
