## 如何使用

1. 先读 [`00-总览.md`](00-总览.md)：了解编号体系、浏览五领域全表（编号｜标题｜会议年份｜一句话核心洞见）、看跨领域 landscape 短评；
2. 再读对应领域的`导读-*.md`：按"必读 5 篇 + 阅读顺序"进入，带着"关键争论点"去读；
3. 单篇精读在 `papers/NNN-*/NNN-*.md`：每篇含信息块、思路还原、公式讲透、怀疑式审读；
4. 想快速定位：用论文简称搜目录名（如 `simlingo`、`hydra-mdp`）。

引用提醒：总览表格中标注"未确认 / 待确认"的会议年份，引用前请以官方程序册或出版社页面复核。
