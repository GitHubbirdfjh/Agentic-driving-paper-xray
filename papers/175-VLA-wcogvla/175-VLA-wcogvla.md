## 一个让 ReCogDrive 被困在慢车道的场景

论文 Fig. 5 摆了一个具体的对比。同一段城市道路，自车后方跟着一辆慢速公交。ReCogDrive（NAVSIM v1 上 90.8 PDMS，当时的前排方法）的选择是：留在当前车道，跟着公交慢慢挪，整段路的通行效率被拖低。WCog-VLA 的选择是：识别出前方公交是"慢"的根源，变道超车，走的路线贴近人类驾驶员的真值轨迹。

这个差别值得停下来看。ReCogDrive 不是"没看见"公交——它的感知和预测都在。它的失败在于规划只回答"给定当前世界，我这条轨迹安全吗"，而不回答"如果我换条道，周围的车会怎么反应"。前者是反应式驾驶：世界是背景板，自车在背景板上找一条不撞的线。后者是主动式驾驶：世界是对手盘，自车的每个动作都会改变对手盘的走法，规划要在"自车动作—他车反应"的联合空间里选。

WCog-VLA 整篇论文就是为第二个问题搭的架子。它的答案分成两层：语义层负责把"他车会怎么反应"想清楚（Game-CoT 博弈推理 + agent token 承载的世界动态），生成层负责把"想清楚的未来"画成物理上站得住的多智能体联合轨迹（ADDT）。两层之间用"场景表示对齐"缝起来，顺带把扩散去噪压到 5 步。

## 作者到底在推翻哪个默认假设

引言的 Fig. 1 把 VLA 里加世界模型这件事分成四代，这个分类本身就是作者的立论武器：

- (a) 动作当文本自回归生成（DriveGPT4、DriveLM、AutoVLA 那一路）；
- (b) VLM 当认知编码器，外挂动作解码器（ORION 的 VAE、ReCogDrive 的扩散）；
- (c) 碎片化的世界预见：把世界建模当辅助语义任务——UniDrive-WM、DriveVLA-W0 做未来图像生成当辅助损失，SGDrive 按场景—智能体—目标分层建世界特征；
- (d) WCog-VLA：语义层预测和生成层演化缝在一起。

作者要推翻的默认假设藏在 (c) 里：**世界模型在 VLA 里是一个辅助预测头**。这个假设下，世界模型输出的是"对未来的描述"（文字、图像、occupancy），规划器另起炉灶。WCog-VLA 的反命题是：世界模型应该直接输出"未来的演化本身"——即自车与周围智能体的联合轨迹，规划就长在这个演化里，不需要第二个规划器。

这个反命题在逻辑上并不显然。反对的声音会说：联合轨迹生成把预测和规划绑死了，万一他车预测错了，自车轨迹跟着错，没有纠错层。但作者的底气不在逻辑，在三张牌。

## 作者手里的三张牌，哪张最硬

**第一张：85k Game-CoT 标注。** 这是数据牌。自动驾驶领域缺的不是"场景描述"数据（DriveLM、NuInstruct 一大把），缺的是"博弈推理"监督：没有人标注过"自车如果变道、后车会让还是会顶"这种 if-what 链条。作者用 Qwen3-VL-Plus（商用大 VLM）搭了一条自动标注管线，拿真值动作当提示反向编出因果链，一次攒出 85k 条。这是审稿人很难否定的东西：数据集贡献独立于方法成败。

**第二张：借来的机制叙事。** ADDT 的"解耦"直接引 DDT（Decoupled Diffusion Transformer, arXiv:2504.05741），"表示对齐"直接引 REPA（arXiv:2410.06940）。两个都是扩散模型社区里已经被接受的技巧，审稿人不用重新学习一套新数学。作者做的只是把"低频语义 vs 高频细节"的冲突翻译成驾驶的语言："多智能体交互建模 vs 精确轨迹恢复"。借来的牌不丢人，但读者要清楚：解耦在这里是工程选择，不是理论必然。

**第三张：四阶段训练，每阶段消融都是正的。** 从 84.4（纯文本）到 85.5（+3D 感知）到 89.3（+ADDT）到 92.9（+RL），每一步都涨。这张牌决定了论文的"工程可信度"，也是我认为最硬的一张——不是因为数字大，而是因为作者敢把每一步的增益摊开，等于把"我这个系统里哪个零件值多少钱"写清楚了。

时间坐标也值得标一下：2026 年 7 月，NAVSIM v1 的 92 分区间已经是红海——同期 LatentVLA 92.4、AutoVLA 92.1、iPad 91.7 全挤在这里。WCog-VLA 的 92.9 只比第二名高 0.5，而这 0.5 里的大头是最后一步 RL（+3.6）。推论是：如果去掉 RL，这篇论文的方法部分（语义+生成双层）落在 89.3，进不了前三。这个结构后面怀疑式审读还会回来。

## 语义层：三路 token 进去，两路读出出来

VLM 主干是 InternVL3-2B：300M 参数的 InternViT 视觉编码器 + Qwen2.5 LLM。输入有三路：

1. 六张环视图像 $I = \\{I_i\\}_{i=1}^6$，走视觉编码器变成 $T_{vision}$；
2. 文本指令 $l_{ins}$（比如"右转"）和自车状态 $S = \\{v, a, T_{hist}\\}$（当前速度、加速度、2 秒历史轨迹按 2Hz 采样），走分词器变成 $T_{text}$；
3. agent token $T_{agent} = \\{t_j^{agent}\\}_{j=1}^{N_a}$，这是论文相对一般 VLA 最不一样的一路。

agent token 的来路值得细看：多视角图像特征先被 BEVFormer 的现成 BEV 编码器抬到鸟瞰图 $F_{BEV}$，再用 TrackFormer（一组可学习的 agent query $Q_{agent}$）对 $F_{BEV}$ 做 cross-attention，把稠密 BEV 压成稀疏的、以智能体为中心的 token。每个 token 携带一个检测到的交通参与者的空间位置和几何特征。直观理解：VLM 原本看的是"像素"，agent token 给它的是"这里有 $N_a$ 个东西，每个东西在哪、多大"——一张结构化的世界清单。

三路 token 沿序列维拼接进 LLM：

$$O_{vision}, O_{text}, O_{agent} = \mathrm{LLM}([T_{vision}, T_{text}, T_{agent}]) \tag{1}$$

然后是关键的**解耦读出**：$O_{agent}$ 走专门的 world head，解码成当前 3D 感知（检测框 $b_i$）和周围智能体的未来轨迹预测（$\tau_{i,t}$）；$O_{vision}$ 和 $O_{text}$ 走语言建模头，输出 Game-CoT 推理文本。

这里有一个论文没有强调、但读者必须看清的细节：**推理文本的读出并不经过 $O_{agent}$**。也就是说，Game-CoT 那四步博弈推理（场景描述→关键对象分析→博弈推理→收益评估）是从视觉和文本隐状态里长出来的，agent token 承载的世界动态知识只通过 LLM 主干内部的注意力混合间接渗进去，没有一条显式的"动态信息→推理文本"的通路。"统一世界认知与推理"的"统一"发生在 trunk 里，读出是分离的。这个设计是务实的（两个头各训各的，互不干扰），但名字里的"统一"比实际机制走得远了一点。

## Game-CoT：四步博弈推理到底在写什么

Game-CoT 是论文的数据贡献，也是"主动驾驶"在语义层的落点。标注管线用 Qwen3-VL-Plus 对 NAVSIM 场景自动生成四步结构化推理：

1. **场景描述**：当前路况、车道结构、交通参与者位置的文字盘点；
2. **关键对象分析**：挑出对决策真正有影响的那几个对象（比如"左前方公交车速 8km/h，持续压制本车道流速"），过滤无关信息；
3. **博弈推理**：把交互形式化成 Stackelberg 博弈——自车是 leader（先行动），周围智能体是 follower（对自车动作做反应）。模型做"if-what"想象：枚举几个候选自车动作（跟驰、变道、减速让行……），对每个动作推断 follower 会怎么反应；
4. **收益评估**：对每种"自车动作→他车反应"的假想结局打分（安全+效率），选最优策略。

最终输出两样东西：最优自车动作，以及推断出的周围智能体的反应。

拿 Fig. 6 的路口左转场景走一遍。场景：自车要在有对向来车的路口左转。

- 第 1 步写下：双向两车道路口，对向一辆车接近，距离约 40 米，速度约 30km/h，本车道无阻挡。
- 第 2 步锁定关键对象：对向来车是唯一的冲突方；它的"意图"（直行还是也转弯）决定一切。
- 第 3 步进入博弈：如果自车现在左转（leader 行动），对向车作为 follower 的反应是什么？直行车的通行优先权高、减速成本大，合理推断是它保持直行、不会为自车让行；如果自车等待，对向车通过后冲突消失。于是"现在转"这个分支的结局是高风险，"等 2 秒再转"是低风险。
- 第 4 步给"等再转"更高收益分，输出这个策略，并写下"对向车将保持直行通过路口"的推断。

基线（没有生成式世界认知的方法）在这个场景里做了什么：它只生成自车轨迹，不预测对向车的联合未来。规划器看到的是一团"对向可能有车"的不确定性，只能被动减速、盲目避让假想的冲突。WCog-VLA 的 ADDT 则直接合成"自车左转 + 对向车直行"的联合轨迹，把不确定性变成具体的未来，自车于是敢执行左转——这就是论文说的 proactive。

但 Game-CoT 有两个诚实的问题。第一，**标注时用了真值动作当提示**（"To minimize hallucinatory outputs… we incorporate Ground-Truth actions as guiding hints"）。管线的真实流程是：先知道人类司机实际做了什么，再让大模型编一条从场景到这个动作的因果链。这是 hindsight rationalization（事后合理化），不是模型自己从博弈中推出策略。数据质量因此取决于 Qwen3-VL-Plus 编故事的能力，而 85k 条标注的一致性、幻觉率，论文没有报告任何数字。第二，**Game-CoT 在推理时不在环路里**。最终上车跑的是 ADDT 扩散路径（0.106 秒），不需要先生成几百个 token 的推理文本。Tab. 5 的数据很直白：VLM 直接输出答案 85.0 PDMS / 1.131s，带上 Game-CoT 文本输出 85.5 / 9.896s——推理文本本身在推理时只值 0.5 个点，却要 9.9 秒。所以 Game-CoT 的真实角色是**训练时的数据蒸馏**：把大模型的博弈推理模式蒸进 2B 小模型的权重里，而不是在线推理。这不减损它的价值，但读者不该把它想象成"车在开的时候一步步想"。

## ADDT：为什么扩散模型要拆成两半

这是论文方法上最硬的一块，值得慢下来。先看输入输出的形状。

记 $x_t \in \mathbb{R}^{N_m \times H \times 3}$ 为扩散时刻 $t$ 的**联合多智能体动作噪声**：$N_m$ 是场景里最多的智能体数（含自车），$H$ 是规划步数（horizon），$3$ 是每步轨迹点的维度（论文没有明说这 3 维是什么，按上下文推断是平面位置+朝向之类的运动学量，**未确认**）。注意这不是"自车轨迹"，而是**所有智能体**的轨迹拼成的张量——这就是"生成式世界演化"和"自车规划器"的根本区别：ADDT 一次去噪，还的是整个世界的未来。

条件输入 $F_{at}$ 是三样东西拼起来的：

$$F_{at} = \mathrm{concat}(E_{act}(x_t), E_{his}(\tau_{his}), \bar{F}_{VLM}) \tag{2a}$$

$E_{act}(x_t)$ 是噪声动作的编码，$E_{his}(\tau_{his})$ 是自车历史动作的编码，$\bar{F}_{VLM}$ 是 VLM 输出 token 的平均池化。condition encoder 吃进去，吐出语义自条件特征：

$$z_t = \mathrm{Encoder}(F_{at}, t, S, F_{VLM}) \tag{2b}$$

其中扩散步数 $t$ 和自车状态 $S$ 通过 AdaLN 调制注入（给物理运动学先验），完整的 VLM 输出 $F_{VLM} = [O_{vision}, O_{text}, O_{agent}]$ 通过 cross-attention 注入（给高级语义先验）。

然后是**表示对齐**，全文最关键的一行：

$$\mathcal{L}_{align} = 1 - \cos(r_*, h_\phi(h_i)) \tag{3}$$

$h_i$ 是 condition encoder 第 $i$ 个 DiT block 的中间特征（实现里取的是第 6 个 block，共 8 个 encoder block）；$r_*$ 是一个**预训练 VAE 编码器**从真值场景里提的隐表示——这个 VAE 按 GenAD 的做法，用 MLP 编码器 + GRU 解码器预训练去重建多智能体轨迹，它的隐空间同时抓住全局交通模式和每个智能体的个性。$h_\phi$ 是一个可学习的投影 MLP，把 $h_i$ 映射到和 $r_*$ 同一空间，再算余弦相似度。

用几何语言说：VAE 的隐空间是一张"物理上合理的交通流形"——真值轨迹都趴在这张流形上。对齐损失就是把 condition encoder 的中间特征往这张流形上拽。没有对齐时，encoder 的 $z_t$ 在隐空间里可以飘到任何地方，decoder 只能靠一遍遍去噪迭代把输出拽回合理区域；有了对齐，$z_t$ 从第一步就被钉在流形附近，decoder 需要的修正步数就少了。这就是"表示对齐减少去噪步数"的全部机制——不是加速了单步，而**减少了需要的步数**。

generation decoder（$N_2 = 8$ 个 DiT block，和 encoder 对称，总共 16 个 block）则只干一件事：恢复高频几何细节。它和 encoder 架构一样，但 AdaLN 里除了 $t$ 还注入 $z_t$（语义对齐的去噪），输出去噪后的联合轨迹：

$$x_{t-1} = \mathrm{Decoder}(F_{at}, t, z_t, F_{VLM}) \tag{4}$$

![ADDT 结构（论文 Fig. 3，第 6 页）](/home/hatch/workspace/your_files/paper-xray-100/papers/175-VLA-wcogvla/paper-fig3-addt.png)
*左：condition encoder（$N_1=8$ 个 DiT block），DiT block 内部有时步与自车状态的 AdaLN（Shift/Scale）、VLM token 的 cross-attention；第 6 个 block 的特征与预训练场景编码器做表示对齐，输出 condition feature $z_t$。右：generation decoder（$N_2=8$），$z_t$ 与时步一起经 AdaLN 注入，经 Action Decoder 输出多智能体联合轨迹。*

"解耦"的动机引自 DDT（arXiv:2504.05741）：单个网络里，编码低频抽象语义和解码高频连续细节是优化上打架的两件事。翻译成驾驶语言：condition encoder 只管"多智能体之间怎么相互影响"（低频、结构），generation decoder 只管"轨迹点的精确几何"（高频、细节）。Tab. 5 的消融把账算得很清楚（5 步去噪）：标准单网络 SDT 87.4 → 只解耦不加对齐（DDT）87.9（+0.5）→ 只加对齐不解耦（ADT）88.6（+1.2）→ 全都要（ADDT）89.3（+1.9）。两项大致可加，对齐的贡献更大。

步数敏感性实验是"加速推理"主张的直接证据：ADDT 从 5 步加到 20 步，PDMS 只从 89.3 涨到 89.6（+0.3）；而无对齐的 DDT 从 5 步到 20 步涨 0.8（87.9→88.7）。以及论文标题级的数字：5 步 ADDT 相对 20 步 SDT 高 0.8 个点（89.3 vs 88.5），推理时间从 0.388s 降到 0.106s（3.7 倍）；相对 VLM 直接文本生成（1.131s）是 10.7 倍加速。验算：$1.131/0.106 = 10.67$，$0.388/0.106 = 3.66$，都对得上。

## 四阶段训练：每个损失项到底在罚什么

训练管线分四段（论文 Fig. 4，第 8 页），每段冻住一部分、只训一部分。这张图的信息密度很高，值得逐段拆。

![四阶段训练流程（论文 Fig. 4，第 8 页）：Stage 1 只训 3D 感知；Stage 2 训图像感知+3D 感知+LLM（ADDT 冻结），吃三类 Drive VQA 数据并经 world head 监督当前感知与未来预测；Stage 3 冻结 VLM 只训 ADDT（VLM token 输入 + 表示对齐 + 多智能体轨迹监督）；Stage 4 只训 ADDT，经 GRPO 接奖励模型做强化微调](/home/hatch/workspace/your_files/paper-xray-100/papers/175-VLA-wcogvla/paper-fig4-training.png)

**Stage 1：3D 感知预训练。** 只训 BEV 编码器和 TrackFormer。监督按 UniAD 的感知训练法：检测头做分类 + 3D 框回归，损失是 focal + L1：
$$\mathcal{L}_{s1} = \lambda_{focal}\mathcal{L}_{focal} + \lambda_{L1}\mathcal{L}_{L1}$$
$\lambda_{focal}$、$\lambda_{L1}$ 的具体值论文没给（**未确认**，补充材料也没发布）。

**Stage 2：VLM 监督微调。** 训 VLM（ADDT 还不存在/冻结），吃三类文本数据：15.8 万条开源驾驶 VQA（DriveLM、CODA-LM、LingoQA、nuScenes-QA、NuInstruct、DriveGPT4），再加 17 万条 NAVSIM 定制样本（8.5 万条轨迹专用 VQA + 8.5 万条 Game-CoT）。总损失：

$$\mathcal{L}_{s2} = \mathcal{L}_{LM} + \lambda_{world}\mathcal{L}_{world} \tag{5}$$

$$\mathcal{L}_{world} = \frac{1}{N_a}\sum_{i=1}^{N_a}\lambda_{box}\mathcal{L}_{L1}(b_i) + \frac{1}{N_aH}\sum_{i=1}^{N_a}\sum_{t=1}^{H}\lambda_{traj}\mathcal{L}_{L1}(\tau_{i,t}) \tag{6}$$

$\mathcal{L}_{LM}$ 是标准语言建模交叉熵（管 Game-CoT 文本和 VQA 回答）；$\mathcal{L}_{world}$ 是 world head 的两项 L1：当前 3D 框 $b_i$ 的定位误差、未来轨迹 $\tau_{i,t}$ 的位移误差，都按智能体数 $N_a$（轨迹再按 horizon $H$）平均。$\lambda_{world}$、$\lambda_{box}$、$\lambda_{traj}$ 的值同样没给（**未确认**）。

注意这里的训练顺序：VLM 先在 15.8 万 VQA 上跑 1 个 epoch，再和 world head 一起在 17 万 NAVSIM 样本上联合训 3 个 epoch。这是典型的"先学说话，再学看路"——防止世界认知损失一上来就把语言能力冲垮。

**Stage 3：ADDT 监督微调。** 冻结 VLM（把它当成语义层世界模型，只出 token 不更新），训 ADDT 的扩散去噪。损失两项：

$$\mathcal{L}_{s3} = \mathcal{L}_{diff} + \lambda_{align}\mathcal{L}_{align} \tag{7}$$

$$\mathcal{L}_{diff} = \mathbb{E}_{z_t, F_{at}, \epsilon\sim\mathcal{N}(0,I)}\left[\|\mathbf{W}\odot(\epsilon - \epsilon_\theta(F_{at}, t, z_t, F_{VLM}))\|_2^2\right] \tag{8}$$

$\mathcal{L}_{diff}$ 是标准 DDPM 噪声预测 L2，但多了一个逐智能体的权重 mask $\mathbf{W}$（Hadamard 逐元素乘）：自车用 $\alpha_{ego}$，周围智能体用 $\alpha_{surr}$，让网络更在乎把自车的轨迹生成准。$\alpha_{ego}$、$\alpha_{surr}$、$\lambda_{align}$ 的值**未确认**。直观理解：$\mathbf{W}$ 是在告诉去噪网络"这 $N_m$ 个智能体里，第 0 个（自车）的误差权重最大"，因为最终开车的是自车。

**Stage 4：强化微调（DiffGRPO）。** 只训 ADDT，用 GRPO 在 NAVSIM 上再跑 10 个 epoch（group size 为 6，原文 "using 6 group sizes"），奖励直接挂钩 PDMS：

$$L_{s4} = \underbrace{-\frac{1}{GT}\sum_{i=1}^{G}\sum_{t=1}^{T}\gamma^{t-1}\log\pi_\theta(x_{t-1}^{(i)}\mid x_t^{(i)})\hat{A}_i}_{L_{RL}} - \underbrace{\lambda_{bc}\frac{1}{GT}\sum_{i=1}^{G}\sum_{t=1}^{T}\log\pi_\theta(\tilde{x}_{t-1}^{(i)}\mid \tilde{x}_t^{(i)})}_{L_{BC}} \tag{9}$$

逐项拆。$G$ 是每组采样的轨迹数，$T$ 是去噪总步数。$\pi_\theta(x_{t-1}^{(i)}\mid x_t^{(i)})$ 是扩散第 $t$ 步的转移概率——GRPO 在这里被"扩散化"了：通常 GRPO 的"动作"是 token，这里的"动作"是每一步去噪。$\hat{A}_i$ 是组内相对优势（同一组 $G$ 条轨迹的奖励减均值除标准差，标准的 GRPO 做法）。$\gamma^{t-1}$ 是折扣：$t$ 越大（越接近纯噪声的早期去噪步）权重越小，因为早期步的转移概率方差大、容易把策略梯度带偏——这是给扩散过程量身定做的稳定技巧。$L_{BC}$ 是行为克隆锚：$\tilde{x}$ 从参考策略 $\pi_{ref}$（SFT 后的模型）采样，$\lambda_{bc}$ 控制"别在探索里把已经学会的开车技能忘掉"。

奖励函数把自车和他车解耦：$r_i = r_{PDMS} - \lambda_{surr}\mathcal{L}_{L1}(\tau_{surr})$。自车质量用 NAVSIM 的 PDMS 打分，他车只要求"预测得准"（未来轨迹 L1 惩罚）。这个设计的潜台词是：RL 只优化自车开得好不好，不让策略为了刷 PDMS 把他车预测带偏。$\lambda_{surr}$、$\lambda_{bc}$、$\gamma$ 的值**未确认**。

硬件：四个阶段全在 4 张 A100 40GB 上跑。ADDT 的 DDPM 训 200 个 epoch，GRPO 训 10 个 epoch。墙钟时间论文没给。

## 数字逐项核实：摘要的每一句话都有证据吗

**主结果（NAVSIM v1，完整四阶段后）：PDMS 92.9。** 子项：NC 99.4、DAC 98.8、TTC 98.5、Comf. 100、EP 87.1。摘要的 "SOTA PDMS 92.9" 有表 1 支撑。几个关键差值我逐项验算过：

| 对比 | 差值 | 论文说法 | 验算 |
|---|---|---|---|
| vs WoTE（相机+激光雷达，88.3） | +4.6 | "improvement of 4.6 PDMS over WoTE" | 92.9−88.3=4.6 ✓ |
| vs QwenVL2.5-8B / InternVL3-8B（83.3） | +9.6 | "by 9.6 PDMS" | 92.9−83.3=9.6 ✓ |
| vs AutoVLA-3B（92.1） | +0.8 | "by at least 0.8"（含 ReCogDrive-2B 90.8，差 2.1） | 92.9−92.1=0.8 ✓ |

纯视觉打过带激光雷达的 WoTE 是真实的（表 1 里 WCog-VLA 的 Lidar 列是空的）。但注意第二名的 LatentVLA 只差 0.5——"SOTA"的领先幅度很薄。

**NAVSIM v2（只跑了三阶段 SFT，没做 RL）：EPDMS 85.9**，子项 NC 98.8、TTC 98.2 最高，EP 85.8。比 DiffusionDrive 的 84.3 高 1.6（85.9−84.3=1.6 ✓）。v2 没上 Stage 4 的原因论文没解释——一个可能的原因是 v2 的扩展指标（含交通灯、车道保持等）下 RL 的奖励塑形更难调，但这只是推测。

**消融 1：四阶段（表 3）。** 纯 Stage 2 文本输出 84.4 → +Stage 1（3D 感知）85.5（+1.1）→ +Stage 3（ADDT）89.3（+3.8）→ +Stage 4（RL）92.9（+3.6）。每一步都涨，最大的一跳是 RL。注意表 3 的 ID 1/2 轨迹是 VLM 按文本 token 生成的，ID 3/4 是 ADDT 生成的连续动作——所以 +3.8 里混着"从离散文本到连续扩散"的范式切换，不全是 ADDT 架构的功劳。更干净的架构对比在表 5。

**消融 2：双层世界认知（表 4，三阶段 SFT 下）。** 都没有 86.5 → 只加语义当前感知 87.0（+0.5）→ 只加语义未来预测 87.2（+0.7）→ 语义两项全加 88.1（+1.6）→ 只加生成层（无语义）87.4（+0.9）→ 全加 89.3（+2.8）。语义和生成各自有效，合起来有协同（2.8 > 1.6+0.9=2.5，略超可加）。

**消融 3：ADDT（表 5）。** 已在前面验算：10.7 倍加速（1.131/0.106）、5 步 ADDT 对 20 步 SDT 高 0.8 个点且快 3.7 倍（0.388/0.106）、步数从 5 加到 20 只涨 0.3。这些数字都对得上，是论文里最扎实的一组实验。

**消融 4：VQA 数据（表 6）。** 只用轨迹 VQA 86.7 → +开源 Drive VQA 88.2（+1.5）→ +Game-CoT 87.5（+0.8）→ 三者全用 89.3（+2.6）。有意思的细节：单加 Drive VQA（88.2）比单加 Game-CoT（87.5）效果好——通用驾驶问答数据的贡献大于博弈推理数据。这和"Game-CoT 是核心创新"的叙事有点拧：最贵的那个数据（85k 大模型标注），边际增益最小。

## 怀疑式审读：七个值得追问的地方

**1. 最大的增益来自 RL，而 RL 的奖励就是评测指标本身。** Stage 4 的 +3.6 是四阶段里最大的一跳，奖励 $r_{PDMS}$ 直接就是 NAVSIM 的 PDMS。PDMS 是非反应式（non-reactive）仿真算出来的开环式规划分数——优化它等于在"考试原题"上做梯度上升。论文没有说明 $r_{PDMS}$ 用的是官方 PDMS 权重还是重加权版本。这里必须放一个参照：我们之前精读 ReCogDrive（101-xray）时发现，它的 RL 增益大头来自把 PDMS 里 progress 项权重从官方的 5.0 翻倍成 10.0，而正文自称用的是标准 PDMS。WCog-VLA 有没有类似的权重操作？论文没给任何奖励实现的细节（补充材料未发布），**无法确认**。在看到代码之前，92.9 里有多少是"开得更好"、有多少是"更会考试"，分不开。

**2. 舒适性 100 分和 EP 87.1 并存，说明 RL 没有走"用舒适换进度"的老路。** 这是加分项。ReCogDrive 在 Bench2Drive 上的舒适性只有 17.45（我们 101-xray 的记录），而 WCog-VLA 在 NAVSIM 上 Comf. 100、EP 87.1——至少在这个基准上，PDMS 奖励没有把车训成横冲直撞。但 NAVSIM 的舒适性子项本身比较宽松，这个 100 分的含金量要打折扣。

**3. "对齐减少去噪步数"的因果链条是推断，不是测量。** 论文的解释是：对齐"维持了 $z_t$ 在相邻去噪步的局部一致性"。但全文没有任何一张图或一个数字直接测量过去噪步之间的 $z_t$ 漂移（比如相邻步余弦距离随步数的曲线）。表 5 的步数敏感性实验（5→20 步只 +0.3）支持"步数可以很少"这个结论，但支持的是结论，不是机制解释。机制解释目前是一个合理的故事——我自绘的示意图也是按这个故事画的，读者要清楚那是示意。

**4. 基线数字的来源没交代。** 表 1 里十几个基线（VADv2、DiffusionDrive、WoTE、AutoVLA、LatentVLA……）是重跑的还是引用的，论文没说。LatentVLA（arXiv:2601.05611）和 WCog-VLA（2026-07）是同期工作，92.4 这个数字如果是引用自 LatentVLA 自己的论文，那两边的评测设置（NAVSIM 版本、navtest 切分）是否完全对齐就**未确认**。0.5 个点的 SOTA 领先，经不起评测设置上的任何小错位。

**5. 缺失的超参数清单很长。** $\lambda_{focal}$、$\lambda_{L1}$、$\lambda_{world}$、$\lambda_{box}$、$\lambda_{traj}$、$\lambda_{align}$、$\alpha_{ego}$、$\alpha_{surr}$、$\lambda_{bc}$、$\gamma$、$\lambda_{surr}$——正文一个没给，补充材料没发布。随机种子数、是否报告均值、训练墙钟时间，同样没有。这篇论文在"能动手复现"的标准下是不及格的，只能做到"能理解机制"。

**6. 两个"统一"都比实际走得远。** 一是"统一世界认知与推理"：读出是分离的（world head 只读 $O_{agent}$，LM head 只读 $O_{vision}/O_{text}$），统一只发生在 trunk 的注意力混合里。二是"桥接语义预测与生成式演化"：桥是单向的——VLM token 作为条件喂给 ADDT，没有从 ADDT 回到 VLM 的反馈。真正的双向桥接（比如生成结果回过来修正语义推理）不存在。

**7. 公平地说，三个地方做得漂亮。** 第一，消融做得细：解耦和对齐各自有隔离实验（DDT/ADT/ADDT 三档），加速主张有步数敏感性曲线支撑，不是空口号。第二，结论里诚实承认局限：语义认知目前只覆盖智能体，"omits the future evolution of road geometry and map topology"——做交通灯、车道线未来演化的后续工作可以直接从这里接。第三，Fig. 1 的四范式分类法：把"VLM+世界模型"这条线上的工作按"世界模型是辅助头还是生成器"切开，这个切法比按"有没有世界模型"切更有信息量，后续 related work 可以直接借用。

## 与 RAMP 的血缘/划界

**血缘。** WCog-VLA 和 RAMP 站在同一条战壕里：都不相信"感知→规划"的单遍流水线能搞定长尾，都认为车需要对"世界会怎么变"有一个显式的模型，并用这个模型实现主动（proactive）而非反应（reactive）驾驶。WCog-VLA 在 2026 年中把这条路线在 NAVSIM 上做到了 92.9，证明了世界模型信息对规划增益的真实性——这是 RAMP 立论时可以引用的外部证据：连单体 VLA 加世界模型都能涨，说明"世界模型有用"这个前提是坚实的。

**划界有四条，每条都是机制级的。**

第一，**世界模型的用法完全不同**。WCog-VLA 的世界模型是**生成式**的：ADDT 直接合成自车+他车的联合轨迹，世界模型就是规划器本身，一次去噪输出未来。RAMP 的世界模型是**预测式**的：只做一次前向，输出的中间预测分布同时喂给两个异构消费者——LLM 调度器的先验，和独立风险验证器的输入。WCog-VLA 的世界模型"演完整个未来"，RAMP 的世界模型"算完分布就交棒"。这是"世界模型即规划器" vs "世界模型即信息源"的区别。

第二，**系统形态不同**。WCog-VLA 是单体系统：一个 VLM + 一个扩散头，一次前向出结果，没有"选哪个规划器"这个问题。RAMP 是多规划器 Agent：LLM 在线调度异构规划器池，调度本身就是决策。WCog-VLA 的 Game-CoT 推理在训练时蒸馏进权重、推理时不在环路；RAMP 的 LLM 在推理时在线工作（调度+仲裁）。

第三，**WCog-VLA 没有记忆，也没有独立的风险仲裁**。它的安全来自"把他车的未来预测准"（预测式安全）；RAMP 的安全来自"对候选轨迹做独立 rollout 校验"（校验式安全）。WCog-VLA 里没有对应 RAMP 支柱 (c) 情景记忆和支柱 (d) 风险仲裁的任何部件，也没有测试时适应。这是 related work 里最干净的一句划界。

第四，**盲区是共通的**。WCog-VLA 结论里承认语义认知缺道路几何与地图拓扑的未来演化——RAMP 的世界模型如果也只预测智能体，会撞上同一堵墙。这既是划界，也是 RAMP 方法设计时要主动回答的问题。

**一句话 related work 定位（可直接用）：** 与用生成式世界模型直接合成多智能体联合轨迹作为规划输出的 WCog-VLA 不同，RAMP 把世界模型当作只做单次前向的预测器，其中间预测分布同时服务于 LLM 调度先验与独立的候选轨迹风险仲裁，并以风险加权情景记忆补上 WCog-VLA 所缺的测试时适应能力。

## 带走什么

两个可迁移的想法。第一，**表示对齐是扩散规划器的通用加速器**：拿一个在真值轨迹上预训练好的 VAE 隐空间去约束去噪网络的中间层，5 步就能达到 20 步 99% 的效果（89.3 vs 89.6）。这个技巧不依赖驾驶，任何"扩散+结构化输出"的任务都能试，代价只是一个预训练 VAE。第二，**用真值动作当提示反向生成推理链**，是给小模型蒸馏"博弈直觉"的廉价数据管线：85k 条 Game-CoT 让 2B 模型在博弈场景下不再当被动观察者。代价是 hindsight bias——模型学到的是"如何解释正确答案"，不是"如何找到正确答案"，用的时候要清楚这个边界。

一个值得做的问题：WCog-VLA 的对齐只钉住了"智能体轨迹"流形，而它自己承认缺了道路几何与地图拓扑的演化。如果把 VAE 的重建对象从"多智能体轨迹"扩大到"轨迹+车道拓扑+红绿灯状态"的联合未来，对齐损失是否还能把去噪步数压在 5 步？如果能，说明这套"流形钉住中间层"的方法是可扩展的；如果不能，说明解耦+对齐的能力上限就在智能体交互这一层——这个答案对 RAMP 的世界模型设计（预测什么、不预测什么）有直接指导意义。
